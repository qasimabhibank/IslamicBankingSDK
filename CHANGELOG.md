# Changelog

All notable changes to **IslamicBankingSDK** are documented in this file.

## [1.0.0] - 2026-08-27

### Added
- Standalone Swift Package (`Package.swift`) for iOS 13+
- Public API: `IslamicBanking.configure` / `startFlow` / `isConfigured`
- Host protocols: `IslamicBankingNetworking`, `IslamicBankingAuthProviding`, `IslamicBankingUIDelegate`
- Built-in `IslamicBankingURLSessionNetworking` + `IslamicBankingTokenAuth` + `IslamicBankingRouteTable`
- Full Murabaha UI (storyboard, XIBs, assets) loaded via `Bundle.module`
- Examples and GitHub-ready documentation
